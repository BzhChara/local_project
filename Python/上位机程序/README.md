# LED亮度检测上位机

Python + PySide6 编写的 Windows 上位机调试程序，用于通过串口读取 16 个通道的 LED 电流 ADC 数据，并以 4x4 卡片和实时曲线显示。

## 当前功能

- 串口参数：`115200, 8N1`
- 通道范围：`1-16`
- 每个通道显示 16 路 LED 电流值
- 每个通道页面使用 4x4 电流卡片
- 点击某个 LED 卡片后，右侧显示该 LED 的实时历史曲线
- 左右箭头切换通道
- 后台持续轮询 16 个通道，切换通道时直接显示已采集数据
- 启动时检查 `requirements.txt` 依赖，缺失时弹窗提示并支持自动安装

## 安装依赖

在项目目录执行：

```powershell
pip install -r requirements.txt
```

如果缺少依赖，程序启动时也会弹窗提示。点击“自动安装”后，会实时显示 pip 安装输出。安装完成后请重新启动程序。

## 启动程序

```powershell
cd "D:\Microsoft VS Code Projects\Python\上位机程序"
python app.py
```

## 串口使用

1. 插入硬件设备。
2. 启动程序。
3. 点击左上角 `选择COM口`。
4. 选择设备串口，例如 `COM5`。
5. 点击 `连接`。
6. 程序会循环读取 1-16 通道。

当前协议读取命令：

```text
A5 5A XX 02 02 00 00 SUM
```

当前协议返回帧：

```text
5A A5 XX 02 40 + 16 个大端 IEEE754 float + SUM
```

`SUM` 为从帧头开始逐字节累加后取低 8 位。

## 仍需硬件确认

- `IHH IHL ILH ILL` 当前按大端 IEEE754 float 解析。
- 单位暂定为 `mA`。
- 你反馈未插灯光时读数约为 `0.001 mA`，这是当前硬件返回值经过 float 解析后的结果。
- 曲线使用原始 float 数据绘制，卡片显示会按小数位格式化，因此卡片和曲线视觉上可能存在精度差异。
